# 员工移动工作台
同一管理端、账号和公司上下文，在窄屏默认使用移动工作台；平台运营账号保留平台后台。电脑现状保留，可手动切换。
底部四栏：工作台、活动、报名订单、我的。工作台以本人今日/本月真实业绩及待跟进客户为主，可下钻本人记录；活动列表默认已参加，公司管理员可切全部。活动操作页仅展示时间、状态、报名订单、榜单、推广，不展示配置详情。
报名订单包括未创建订单的留资，按活动权限查询；列表展示姓名、电话、销售、状态、金额及时间；详情展示填写内容和支付退款信息。活动筛选、搜索、分页、错误重试齐全。
公司月榜固定公司可见，活动榜遵守 self/group/all；个人/活动分组榜保留零业绩，组可展开；报名按真实成功人数，团购按实际支付金额；30秒刷新且后台暂停，复用捷报。
员工推广必须服务端归属，分享客户活动短链接和二维码；微信内配置JS-SDK，普通浏览器复制；禁止把后台链接当活动链接。
公司切换沿用现有取消请求、清空状态、重载机制，不新增绕过隔离方式。无数据库结构变化。
视觉：业务工具式紧凑布局、6px圆角、44px触控、固定底栏与安全区、无整页横向滚动。沿用Vben品牌与字体token（覆盖UI skill的默认禁用规则）。
