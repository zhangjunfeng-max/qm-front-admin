# 团购营销管理端应用

应用对接 `group-biz`，由平台管理、公司管理和移动浏览器三类界面组成。页面使用 Vben 的布局、路由和状态管理，业务组件使用 Ant Design Vue。

新增或修改独立列表页时，遵循仓库根目录 [AGENTS.md](../../AGENTS.md) 的字段、高度、滚动和分页规范。

## 启动

在仓库根目录运行：

```sh
pnpm install
pnpm dev:antd
```

默认访问 `http://localhost:5666`。开发代理把 `/api/v1` 转发到 `http://127.0.0.1:8080`；修改代理后需重新启动 Vite。

## 登录与公司上下文

登录只提交手机号和密码。浏览器先获取一次性挑战，再用 RSA-OAEP/SHA-256 加密密码。生产环境必须使用 HTTPS。

账号可能属于多个公司。只有一个可用公司时直接进入；多个公司时先选择。公司的业务访问令牌固定当前公司，客户端不能通过请求参数切换公司。

切换公司前会刷新凭证，并取消旧公司的在途请求、上传、页面权限和缓存。服务到期、公司停用或员工停用后不能继续进入对应公司。

平台权限独立于公司角色。平台管理员可以跨公司维护系统，但不能作为活动员工参与活动或归属业绩；公司管理员可以参与本公司活动。

## 当前页面

| 页面 | 说明 |
| --- | --- |
| `/home` | 公司运营总览、快捷入口和公司资料；单公司账号隐藏公司切换 |
| `/activities` | 活动列表、编辑、审核流转、发布、归档和推广 |
| `/activities/:id` | 活动信息、员工分组、订单、客户、业绩和运营工作台 |
| `/employees` | 当前公司员工管理 |
| `/stores` | 当前公司门店管理 |
| `/miniapps` | 当前公司小程序 AppID 管理 |
| `/customers` | 当前公司客户与报名记录 |
| `/orders` | 当前公司订单、支付状态和退款 |
| `/notifications` | 站内通知 |
| `/m/*` | 手机浏览器精简业绩、订单和活动工作台 |
| `/platform/overview` | 平台运营总览 |
| `/platform/tenants` | 公司接入与公司资料 |
| `/platform/users` | 全局用户和平台管理员授权 |
| `/platform/activities` | 平台活动审核 |
| `/platform/payments` | 微信商户账户、公司绑定和支付路由 |
| `/platform/music` | 平台音乐库 |

活动支持 13 套主题、动态报名表单、门店多选、员工范围、业绩可见范围、分享素材、平台音乐、虚拟展示人数、审核和推广。已审核活动可以修改不影响交易口径的展示配置；团购核心定价、表单结构、渠道、小程序和起止时间受更严格限制，起止时间仅平台管理员可调整。

图片和视频在浏览器本地完成压缩、预览和去重，保存活动时才上传。背景音乐只能从平台音乐库选择。

## 接口约定

- 当前 API 前缀为 `/api/v1`。
- 成功响应直接返回业务 JSON；业务错误使用 HTTP 状态码和 `message`。
- 普通请求使用 Bearer access token。认证失败时团队共享一次刷新，成功后重放原请求一次。
- 刷新失败、权限撤销或公司关系失效时立即清除当前上下文。
- 响应必须是当前版本字段；前端不维护旧字段映射。

## 验证

```sh
pnpm --filter @vben/web-antd typecheck
pnpm exec vitest run apps/web-antd/src/api/__tests__
pnpm --filter @vben/web-antd build
```

生产环境默认请求同源 `/api/v1`。独立 API 域名通过 `VITE_GLOB_API_URL` 配置，并在后端 `CORS_ALLOWED_ORIGINS` 中加入前端来源。
